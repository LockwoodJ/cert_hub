What You Need to Learn

  • Prepare smaller laser files correctly.
  • Use approved materials only.
  • Set focus and test settings.
  • Monitor the laser during the entire job.

Certification Focus

This page prepares you for the hands-on check. Passing the quiz does not replace the instructor sign-off.

Ask before acting: If the setup does not match the training, stop and ask your instructor.
Real FabLab Scenario: A student brings in unknown plastic for a quick engraving. What should happen? The job should not run until the material is identified and approved.

Student Procedure

  1. Confirm your material is approved and fits the smaller work area.
  2. Prepare the file with clear operations.
  3. Set focus and origin according to classroom procedure.
  4. Run a low-risk test on scrap if needed.
  5. Start the job only after instructor approval.
  6. Stay with the laser until it is complete.

Before You Start

  • No unknown materials.
  • Ventilation active.
  • Focus checked.
  • Job monitored.

Stop Immediately If...

  • The tool makes an unusual sound.
  • The material moves unexpectedly.
  • You smell burning, see smoke, or notice heat where it should not be.
  • You are unsure what the next step should be.
