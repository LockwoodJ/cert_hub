What You Need Before Using a Tool

  • Complete the required certification level.
  • Read the tool training page.
  • Pass the certification quiz when required.
  • Complete any hands-on instructor check.
  • Use the correct file type, material, PPE, and setup.

FAQ

Can I use a tool today?

Only if you are certified, approved, and using the tool for an approved project.

What if I am not sure what to do?

Stop before acting. Ask for help before using equipment, changing settings, or restarting a failed job.

What file type do I need?

It depends on the tool. Check the tool page before submitting or preparing your file.

What if my print or job fails?

Document what happened, identify the likely cause, and use the failure as evidence for your next attempt.

Does passing a quiz mean I can use the tool?

No. Some tools also require hands-on approval before independent use.

Where do I begin?

Start with Level 1 and the safety contract, then move through the pathway in order.
