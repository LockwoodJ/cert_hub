What You Need to Learn

  • Secure stock on the router bed.
  • Choose feeds/speeds appropriate to the material.
  • Set origin and safe Z height.
  • Keep clear of moving parts.

Certification Focus

This page prepares you for the hands-on check. Passing the quiz does not replace the instructor sign-off.

Ask before acting: If the setup does not match the training, stop and ask your instructor.
Real FabLab Scenario: A toolpath preview shows the bit crossing a clamp. What should happen? Do not run the job; change the setup or toolpath.

Student Procedure

  1. Mount the correct bit with instructor approval.
  2. Secure stock flat on the spoilboard.
  3. Set X/Y/Z zero using the classroom method.
  4. Preview the job and verify clearance.
  5. Run the first pass slowly and watch for movement or chatter.
  6. Vacuum chips only when safe and approved.

Before You Start

  • Bit tight.
  • Stock secure.
  • Clearance verified.
  • Stop control known.

Stop Immediately If...

  • The tool makes an unusual sound.
  • The material moves unexpectedly.
  • You smell burning, see smoke, or notice heat where it should not be.
  • You are unsure what the next step should be.
